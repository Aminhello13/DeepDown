# SECURITY.md

## Reporting a Vulnerability

Email: `security@darxone.org`

DO NOT submit vulnerability reports as GitHub Issues or PR comments.

## Scope

This policy applies to:
- The DeepDown registry repository
- The DeepDown desktop/mobile application (private repo)

## Out of scope

- Source websites listed in the registry — their own security is their responsibility
- User's own IP and network security

## License Verification

DeepDown uses encrypted license verification. The license server is a minimal HTTP endpoint hosted on a separate infrastructure and is not accessible to the general public.
