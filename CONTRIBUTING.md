# Contributing to DeepDown Registry

Thank you for helping expand DeepDown's source registry!

## How to Add a Source

1. **Fork** this repository
2. **Choose a directory:**
   - `official/` — official, verifiable source sites
   - `public/` — open-access file hosting sites
   - `regional/` — region-specific sources (IR, CN, RU, etc.)
3. **Create a YAML file** following the [schema](registry/schema.yml)
4. **Open a Pull Request**

## Source Requirements

- Site must be publicly accessible (no login walls)
- All download content must be legal (no warez, cracked software, or copyrighted material distributed without license)
- Direct or easily downloadable files

## Contribution Best Practices

✅ Good:
- Add official mirrors (Ubuntu, Kali, Fedora)
- Add open-source project pages (GitHub releases, GitLab, BitBucket)
- Add regional/specialized content sources
- With proper category and language tags

❌ Bad:
- Warez, torrents, cracked software
- Password-protected links
- Fraudulent/malware sites
- Links that require login/registration

## Code of Conduct

Don't be toxic. Contribution is welcome regardless of nationality, proficiency, or identity.

If you're new to GitHub:
1. Read [CONTRIBUTING.md](CONTRIBUTING.md)
2. Follow the [Code of Conduct](CODE_OF_CONDUCT.md)
3. Ask questions in Issues, not PR comments

## Security

If you find a security vulnerability in DeepDown, DO NOT open a public issue. Email `security@darxone.org`.
